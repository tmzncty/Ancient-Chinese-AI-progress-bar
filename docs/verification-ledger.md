# “他们说的”与“我们验过的”不是一回事

> 本页不是论文打假榜，也不是给作者判诚信分。
>
> 它只回答一个更朴素的问题：**这个仓库现在究竟亲手确认到了哪一步？**

古文 AI 很容易出现一种叙述滑坡：

```text
论文说结果很好
    ↓
有一篇正式发表的论文
    ↓
有一个 GitHub 仓库
    ↓
“代码开源”
    ↓
“数据公开”
    ↓
“任何人都能复现”
    ↓
“所以这个能力已经解决”
```

这几句话并不等价。

从 2026-08-28 起，本仓库把**能力判断**与**证据验证状态**分开记录：

- [`progress.yaml`](../progress.yaml)：我们对任务成熟度的当前判断；
- [`verification.yaml`](../verification.yaml)：支撑这些判断的来源到底检查到了哪一步；
- `experiments/runs/`：只有真正由本仓库运行并留下环境、输入、输出、指标的实验，才允许标为 `reproduced_here`。

---

## 1. 五级验证梯子

| 级别 | 我们真正能说什么 | 不能偷换成什么 |
|---|---|---|
| L0 | “有人这么说” | 事实 |
| L1 | “我们找到了原论文/原项目，原文确实这么说” | 结果已复现 |
| L2 | “代码/数据/模型等公开物料至少部分真实存在，并检查过可访问性” | 论文表格已跑出来 |
| L3 | “找到独立复现，或这是一个可直接观察的长期真实工作流” | 所有场景均可靠 |
| L4 | “本仓库按记录的版本、输入和命令亲自跑过” | 普遍真理 |

**会议级别不参与这条梯子。** ACL、IJCAI、LREC、期刊都能提高我们对“这是认真研究”的先验信任，但不能替代实验复现。

---

## 2. 目前最值得警惕的几种语言

### 2.1 “公开数据”

至少可能有五种完全不同的意思：

1. 点链接直接下载；
2. 注册后下载；
3. 签协议后下载；
4. 仅高校/科研机构可申请；
5. README 说“将公开”，但当前仓库里没有。

所以本仓库不再只写 `data: yes/no`，而用 `public / gated / partial / unavailable / unknown`。

### 2.2 “开源”

也可能只是：

- 放了推理示例，没有训练代码；
- 放了评测脚本，没有 benchmark 数据；
- 放了模型权重，没有训练语料；
- 放了数据，没有论文中所用的清洗/划分脚本；
- 放了一个“项目主页仓库”，真正实验代码根本不在里面；
- 放了全部文件，但版本和论文跑表时已经不一致。

因此“GitHub 图标亮着”只够证明 GitHub 图标亮着。

### 2.3 “SOTA / 显著优于”

在本仓库里必须翻译成：

> 作者在其指定的数据、指标、模型版本和实验条件下报告了更高结果。

如果我们没重跑，就不写成：

> 这个模型就是更强。

### 2.4 “可复现”

本仓库要求至少回答：

- 代码 commit 是什么？
- 数据版本是什么？
- 模型权重是什么？
- 推理参数是什么？
- 随机种子是什么？
- 评测脚本是什么？
- 原始输出保留了吗？
- 指标能重新从输出算出来吗？

缺一两项不一定意味着研究不好，但意味着我们应该老实写“缺一两项”。

## 3. 第一轮核查发现

### MCS-Bench：**论文公开，代码部分公开，数据受限**

论文的 7 个子领域、45 个任务、37 个 MLLM 和“最佳平均分仍低于 50”等陈述可以在 ACL Anthology 与项目 README 中互相对应。

但是截至本轮核查，benchmark 数据并不是匿名用户直接下载：项目要求下载申请表，由高校/科研机构人员签字（并建议盖章），提交相关近期论文，经人工审核后获得下载方式。

更直接地看它当前 GitHub 根目录：能看到申请表、README、`calculate_metrics.py` 和展示图片；看不到一个可直接 clone 下来的完整 benchmark 数据目录。

所以我们可以说：

- ✅ 论文存在；
- ✅ 公开仓库存在；
- ◐ 有指标计算代码；
- 🔒 数据是 **gated**；
- ❌ 本仓库没有重跑 37 个模型；
- ❌ 因而 `<50` 仍是**作者报告值**。

这不是批评它“造假”，只是阻止一句“公开 benchmark”在传播过程中偷偷变成“任何人随手可复现”。

### ChunQiuTR：**物料透明度较好，但我们仍未复现结果**

它不是只有 README。当前根目录能直接看到 `dataset/`、`src/`、`evaluate.py`、`main.py`、若干检索评测脚本和 `requirements.txt`；项目还说明发布派生 benchmark artifacts、时间键、qrels、索引等。对原始 Wikisource 文本记录 revision `oldid`，并提供重新下载的方法。

这是很好的 provenance 习惯。

但本仓库仍然只给 L2，因为我们没有真正训练 CTD、跑完整检索并复算论文表格。

### AncientDoc：**有论文、有数据链接，不等于“代码已经公开”**

这一项是本轮审计里很有教育意义的自我纠错。

最初看到 ACL 论文、GitHub 仓库和 README 的 “Dataset / Models” 徽章时，我们一度把它记成 `code: public`。继续直接检查仓库后发现：当前仓库本质上是一个项目主页，根目录主要是 README、HTML/CSS/JS 和 assets；并没有看到训练/评测代码树。

README 的 Dataset 确实链接到 Hugging Face，并声明 CC0；但同一页上的 Models 按钮还是字面量 `link_to_models` 占位符，“Weights & Logs” 又指回 arXiv 论文。

所以现在改成：

- ✅ 正式论文；
- ✅ 数据链接可见；
- ⚠️ 完整实验代码：**未在已检查仓库确认**；
- ⚠️ baseline weights/logs：**未由当前链接确认**；
- ❌ baseline 表格没有在本站重跑。

注意，这也不是说“作者一定没在别处放代码”。我们只能说：**我们检查到的这个项目仓库里没有确认到。**

### WenyanGPT：**模型和数据确实能找到，不等于论文比较表已验证**

IJCAI 论文存在；Hugging Face 上可以找到 `Wenyanmuc/WenyanGPT` 模型权重，也存在同名数据仓。

因此“什么都没放”是不对的。

但仍有三个不同问题：

1. 公共数据仓中的每一部分与论文描述的预训练、SFT、WenyanBENCH split 如何一一对应？
2. 完整训练流水线是否足够明确到可重建？
3. “显著优于其他先进 LLM”的表格能否由第三方重新跑出？

本仓库现在都没有亲自证明，所以结果仍标 `author_reported`。

### XunziALLM：**有可运行代码，不等于训练过程完全开放**

直接检查仓库可以看到 examples、requirements、模型下载脚本、web、教程和 sample data，模型也确实有公开发布。

因此把它说成“只有 README”也不公平。

但这些主要证明的是：**模型项目存在，而且公开了相当一部分使用侧物料。** 它们并不会自动回答完整训练数据、训练流程、所有版本的 benchmark 可复现性等问题。

所以当前写成 `code: partial / data: partial / model: public` 更准确。

### GuwenBERT：**公开权重与公开训练代码仍然是两回事**

GuwenBERT 的 README、训练说明和模型权重链接都真实可见；README 也报告了训练语料规模和 NER 提升，并主动提醒实验结果受数据、超参数、随机种子和设备影响。

但继续检查 GitHub 根目录后，它目前主要是 README / LICENSE / assets，没有看到训练或评测代码树。因此审计状态从先前过于宽松的 `code: public` 改成 `code: unavailable`（意为：**在当前检查到的项目物料中未见公开代码**，不是证明代码世界上不存在）。

这正是验证账本要允许“往回改格子”的原因。

### ACLUE / CHisIEC / UD-Kanbun：**公开物料确实比一句 README 更实在**

- ACLUE 根目录直接有 `data/`、`script/`、`src/`，还单列数据许可；
- CHisIEC 根目录直接有 `code/` 与 `data/`；
- UD-Kanbun 有 `setup.py`、包源码、notebook 和可安装工具链。

但这里也仍然只到 L2：**文件存在**不等于**论文结果已经被我们重算**。

## 4. 为什么“没有复现”不等于“不可信”

否则这套系统会滑向另一种蠢办法：

> 我没亲手训练过，所以所有论文都是假的。

当然不是。

合理的表达是：

```text
论文报告值          = 有价值的证据
同行评审            = 有价值的质量筛选
公开代码/数据       = 提高可检查性
第三方复现          = 再提高可信度
本仓库亲自复现      = 我们终于可以说“我们也跑到了”
```

它们是**累积证据**，不是非黑即白。

## 5. 一个以后很有用的句式规范

### 未复现

> EvaHan2024 论文**报告**封闭赛道最佳断句 F1 为 88.47%。本仓库已核对原论文表述，但尚未重跑参赛系统。

### 物料已检查

> ChunQiuTR 的公开仓库**包含**训练与评测脚本，并记录源文本 revision 信息；本仓库尚未复现论文实验结果。

### 本仓库复现

只有 `experiments/runs/*.yaml` 对应记录存在且校验通过后才能写：

> 在 `<commit>`、`<dataset revision>`、`<model hash>` 与所列参数下，本仓库重新得到 `<metric>`；与论文报告值相差 `<delta>`。

## 7. 欢迎来“补格子”，但不要来“补信仰”

如果你真的复现过某项工作，最有价值的 PR 不是：

> 这个论文我觉得很靠谱。

而是：

> 我在这个 commit、这份数据、这张卡、这个随机种子下跑了三次。原论文 88.47，我得到 87.9 / 88.1 / 88.0。原始输出和评分脚本都在这里。

这才是这个仓库以后最想收的东西。
